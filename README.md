# Проект "Электронная коммерция"

## Описание

Этот проект представляет собой веб-приложение электронной коммерции, разработанное с использованием фреймворка Django. Он предназначен для демонстрации основных функций интернет-магазина, включая отображение товаров, страницу с контактной информацией и форму обратной связи. Также включает раздел блога для улучшения SEO и взаимодействия с пользователями.

## Технологии

Проект разработан с использованием следующих технологий:

- Python 3.12 — язык программирования.
- Django 5.2 — веб-фреймворк для разработки веб-приложений.
- Bootstrap 4 — библиотека для стилизации интерфейса.
- PostgreSQL — база данных для разработки.
- Django Admin — встроенная система управления контентом.
- HTML/CSS — языки разметки и оформления для создания пользовательского интерфейса.
- Bootstrap — для стилизации интерфейса.                     


## Установка

Для установки и настройки проекта выполните следующие шаги:

1. Клонируйте репозиторий:

      git clone https://github.com/Vitaly-Shcheglov/Django-e-commerce.git


2. Создайте и активируйте виртуальное окружение:

   Для Windows:

      python -m venv .venv
   .\.venv\Scripts\activate

   Для macOS и Linux:

      python3 -m venv .venv
   source .venv/bin/activate


3. Установите зависимости:

   Убедитесь, что у вас есть файл requirements.txt в корне проекта. Если его нет, создайте его и добавьте туда необходимые зависимости:

      pip install django

   Затем установите все зависимости:

      pip install -r requirements.txt


4. Примените миграции:

      python manage.py migrate


5. Запустите сервер:

      python manage.py runserver 8080

   Теперь вы можете открыть браузер и перейти по адресу [http://localhost:8080](http://localhost:8080).
             

6. Добавление товара:
             
   Чтобы перейти в раздел добавления товара, введите адрес http://127.0.0.1:8080/add_product/. Или, если вы используете другой порт, укажите соответствующий порт.
             
             
7. Работа с блогом:
             
   Чтобы перейти в раздел блога, вам нужно ввести адрес http://127.0.0.1:8080/blog/.
             
   Если вы хотите перейти к конкретной статье, вы можете использовать URL в следующем формате http://127.0.0.1:8080/blog/post/<id>/. Где <id> — это идентификатор статьи в базе данных. Например, если у вас есть статья с ID 19, URL будет:http://127.0.0.1:8080/blog/post/19/
             
   Чтобы добавить новую статью в блоге, используйте следующий URL: http://127.0.0.1:8080/blog/add/.


## Настройка проекта

- Создание приложения: В проекте создано приложение catalog, которое отвечает за отображение товаров и контактной информации.

## Функциональность

- Главная страница: Отображает приветственное сообщение и основную информацию о магазине.
- Контактная информация: Страница с формой обратной связи, где пользователи могут отправлять свои сообщения.
- Django ORM: Подключение PostgreSQL к проекту, создание и настройка моделей Product и Category, перенос их в базу данных с помощью миграций, регистрация и настройка модели в админке, наполнение базы данных через Django shell, создание фикстуры для моделей и реализация кастомных команд для добавления тестовых данных.
- Шаблонизация: 7.	На главной странице отображается список товаров, и каждое описание товара ограничено первыми 100 символами, пользователи могут просмотреть всю информацию о конкретном товаре, перейдя на соответствующую страницу, для упрощения управления кодом был выделен базовый шаблон, который включает общие элементы страницы, такие как шапка, подвал и стили, создан подшаблон для отображения главного меню, который можно использовать в других шаблонах.
- Блог: Раздел блога, где пользователи могут просматривать статьи, создавать новые записи и редактировать существующие.

## Команды для разработки

- Запуск сервера: Чтобы запустить сервер, используйте команду:

    python manage.py runserver 8080


- Создание миграции: Для создания миграций используйте команду:

    python manage.py makemigrations


- Применение миграций: Для применения миграций используйте команду:

    python manage.py migrate

- Создание администратора для доступа к админке:

    python manage.py createsuperuser

- Открыnие интерактивной оболочки Python для работы с Django:

    python manage.py shell


## Задачи по Django ORM

1. Подключение и работа с базой данных PostgreSQL.
2. Создание и управление моделями Product и Category, которые позволяют хранить информацию о продуктах и их категориях.
3. Реализация миграций для синхронизации структуры базы данных с моделями.
4. Администрирование через интерфейс Django Admin с возможностью фильтрации и поиска продуктов.
5. Использование Django shell для заполнения базы данных и выполнения запросов.
6. Создание фикстур для начального наполнения базы данных.
7. Реализация кастомной команды для добавления тестовых продуктов.
8. Дополнительные функции, такие как выборка последних созданных продуктов и создание модели для хранения контактных данных.
             

## Задачи по шаблонизации

1.	Реализация контроллера, отвечающего за отображение информации о товаре. Создание шаблона, в котором отображаются все детали товара.
2.	Изменение шаблона главной страницы для отображения всех товаров с использованием цикла. Описание товаров ограничено первыми 100 символами для одинакового оформления карточек товаров.
3.	Создание базового шаблона с общими элементами страницы, а также подшаблона для главного меню, чтобы минимизировать дублирование кода.
4.	Реализация формы для добавления новых товаров, а также настройка функциональности для постраничного вывода списка товаров.


## Задачи по блогу

1. Перевод контроллеров с FBV на CBV: Все контроллеры приложения catalog переведены в CBV.
2. Создание нового приложения для блога и добавление его в файл settings.py.
3. Создание модели блоговой записи со следующими полями:
   - заголовок,
   - содержимое,
   - превью (изображение),
   - дата создания,
   - признак публикации (булевое поле),
   - количество просмотров.
4. Реализация полного CRUD для новой модели, используя CBV.
5. Увеличение счетчика просмотров: при открытии отдельной статьи увеличивать счетчик просмотров.
6. Фильтрация опубликованных статей: выводить в список статей только те, которые имеют положительный признак публикации.
7. Перенаправление после редактирования: после успешного редактирования записи перенаправлять пользователя на просмотр этой статьи.
8. Дополнительное задание: Когда статья достигает 100 просмотров, отправляйте себе на почту поздравление с достижением.
